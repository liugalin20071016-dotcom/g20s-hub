G20S Hub 免安装版
==================

将兼容的 2.4G 飞鼠遥控器用于 Windows 上的语音输入、应用操作和窗口切换。
默认配置按 G20S Pro 编写；其他设备可能需要修改源码中的设备识别和键位绑定。

运行
  需要 Windows 10 / 11 和 .NET Framework 4.8。
  双击 G20SHub.exe，程序会显示在任务栏右下角的托盘区域。
  程序使用 Windows 自带接口，无需第三方驱动或库。
  语音输入需要安装相应输入法，并按 config.json 设置快捷键和录音进程。

配置与数据
  保留 exe 旁边的 config.json，程序会将配置、圆环设置（ring.json）和日志（logs\）
  写入这个文件夹。config.json 定义应用匹配、动作和时间阈值；默认键位绑定在源码
  src/Actions/Hub.cs 中。架构和适配方法见仓库 README.md。

暂停与退出
  真键盘 Ctrl+Alt+F12 可暂停或恢复自定义动作。
  托盘菜单提供圆环设置、日志、暂停、重启、开机自启、打开数据文件夹和退出。
  删除程序前，请先关闭开机自启并退出程序；随后删除整个免安装文件夹即可。
